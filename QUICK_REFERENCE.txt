SELECTION SCREEN PARAMETERS:
────────────────────────────
Parameter               Type          Required  Description
────────────────────────────────────────────────────────────────
Material Type (p_mtart) MARA-MTART    YES       Which type to fetch
Material Number (so_matnr) Select-Opt NO        Specific materials
Industry Sector (so_mbrsh) Select-Opt NO        Filter by sector

FIELDS DISPLAYED:
─────────────────
• Material Number (material_number) - From MARA-MATNR
• Material Type (material_type) - From MARA-MTART
• Industry Sector (industry_sector) - From MARA-MBRSH

KEY FEATURES:
─────────────
✓ SELECT with WHERE clause filtering
✓ TRY-CATCH for SQL error handling
✓ Input validation checks
✓ F4 help for material types
✓ Count of retrieved records
✓ Professional report formatting
✓ Color-coded headers

DATABASE TABLE ACCESSED:
───────────────────────
MARA - Material Master
  └─ Status: NOT cloud-ready (Not To Be Released)
  └─ Predecessor views available

FORMS/ROUTINES:
───────────────
• fetch_material_data() - Database query
• display_material_data() - Report output
• display_statistics() - Summary info
• validate_input() - Check material type exists
• get_material_types() - F4 help for selection

EXECUTION FLOW:
───────────────
1. User fills selection screen
2. AT SELECTION-SCREEN: Validation occurs
3. START-OF-SELECTION: Data fetched
4. END-OF-SELECTION: Results displayed
5. Statistics shown

SAMPLE USAGE:
─────────────
Material Type: FERT
Material Number: MAT001 to MAT999 (optional)
Industry Sector: 01 to 09 (optional)
→ Returns all FERT type materials in those ranges
